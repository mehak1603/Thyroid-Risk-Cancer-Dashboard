 # 🦋 Thyroid Cancer Risk Analysis Dashboard | Power BI

## 📊 Project Overview
This project focuses on analyzing thyroid cancer risk factors using an interactive Power BI dashboard. It presents health-related data through visualizations, charts, and key performance indicators (KPIs) to make data easier to understand.

## 🎯 Objectives
- Analyze thyroid cancer-related data.
- Identify important risk factors and patterns.
- Create interactive data visualizations.
- Present meaningful insights through a dashboard.

## 🛠️ Tools & Technologies
- Power BI
- Microsoft Excel
- Data Cleaning
- Data Analysis
- Data Visualization

## 📈 Dashboard Features
- Interactive charts and graphs
- Key Performance Indicators (KPIs)
- Risk factor analysis
- Data-driven insights
- User-friendly dashboard design

## 🔍 Key Insights
The dashboard helps explore patterns and relationships between different health-related factors and thyroid cancer risk.
